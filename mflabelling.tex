  \begin{abstract}
    We show that, for every integer $t\ge 1$, there exists a $(1+o(1))\log n$-bit adjacency labelling scheme for the class of $K_t$-minor-free graphs. Equivalently, for every integer $t\ge 1$, there exists an $n^{1+o(1)}$-vertex graph $U_{n,t}$ that contains every $n$-vertex $K_t$-minor-free graph as an induced subgraph.
  \end{abstract}

  \section{Introduction}

  Let $f:\N\to\N$.  A graph family $\mathcal{G}$ \defin{admits an $f(n)$-bit adjacency-labelling scheme} if there is a function $\tau:(\{0,1\}^*)^2\to\{0,1\}$ such that, for each $n\in\N$, each $n$-vertex graph $G$ in $\mathcal{G}$, there exists a function  $\lambda:V(G)\to\{0,1\}^*=\lambda_{G}$ such that,
  \begin{itemize}
    \item for each $v,w\in V(G)$, $\tau(\lambda_\omega(v),\lambda(w))=1$ if and only if $vw\in E(G)$; and
    \item for each $v\in V(G)$, $|\lambda(v)|\le f(n)$.
  \end{itemize}
  The function $\tau$ is called an \defin{adjacency tester} and the function $\lambda$ is called a (vertex) \defin{labelling} of $G$.

  A graph $U$ is (induced) \defin{universal} for a set $S$ of graphs if, for each $G\in S$, $U$ contains an induced subgraph that is ismorphic to $G$.  Let $p:\N\to\N$. A graph family $\mathcal{G}$ \defin{admits $p(n)$-vertex universal graphs} if, for each positive integer $n$, there exists a $p(n)$-vertex graph $U_n$ that is universal for the set of $n$-vertex graphs in $\mathcal{G}$.   A classic observation is the following equivalence between adjacency labelling schemes and universal graphs:

  \begin{fact}
    A graph family $\mathcal{G}$ admits an $f(n)$-bit adjacency-labelling scheme if and only if $\mathcal{G}$ admits $2^{f(n)}$-vertex universal graphs.
  \end{fact}

  Several minor-closed classes of graphs admit $(1+o(1))\log n$-bit adjacency labelling schemes, including forests, graphs of bounded treewidth, planar graphs, graphs of bounded genus, and (most generally) apex-minor-free graphs:\footnote{A graph $H$ is an \defin{apex graph} if $H$ contains a vertex $v$ such that $H-v$ is planar.  A graph family $\mathcal{G}$ is \defin{apex-minor-free} if there exists an apex graph $H$ such that no graph in $\mathcal{G}$ contains $H$ as a minor.}

  \begin{thm}[\citet{dujmovic.esperet.ea:adjacency}]\label{apex_minor_free}
    For each fixed apex graph $H$, the class of $H$-minor-free graphs
    \begin{itemize}[nosep,nolistsep]
      \item admits a $(1+o(1))\log n$-bit adjacency labelling scheme; and

      \item admits $n^{1+o(1)}$-vertex universal graphs.
    \end{itemize}
  \end{thm}

  In addition to these, several ``beyond-planar'' graph classes including several non-minor-closed generalizations of $k$-planar graphs admit $(\log n+o(\log n))$-bit adjacency labelling schemes.

  One collection of graph classes that is conspicuously absent from this list is the class of $K_t$-minor-free graphs for any $t\ge 6$.  Indeed, if such a result is true for every fixed positive integer $t$, then this would remove the requirement, in \cref{apex_minor_free}, that the graph $H$ be an apex graph.\footnote{Since $K_t$ contains every $t$-vertex graph as a minor, every $H$-minor-free graph is a $K_{|V(H)|}$-minor-free graph.  Any result for the class of $K_t$-minor-free graphs implies the result for $H$-minor-free graphs for any $t$-vertex graph $H$.}
  The best known result in this direction is obtained by combining a $(1+o(1))\log n$-bit labelling scheme of \citet{gavoille.labourel:shorter} for bounded treewidth graphs with a result of \citet{devos.ding.ea:excluding} which states that edges of each $K_t$-minor-free graph can be partitioned into two graphs, each having bounded treewidth:

  \begin{thm}[\citet{gavoille.labourel:shorter} with \citet{devos.ding.ea:excluding}]\label{old_best}
    For each fixed graph $H$, the class of $H$-minor-free graphs
    \begin{itemize}[nosep,nolistsep]
      \item admits a $(2+o(1))\log n$-bit adjacency labelling scheme; and

      \item admits $n^{2+o(1)}$-vertex universal graphs.
    \end{itemize}
  \end{thm}

  \citet{dujmovic.esperet.ea:adjacency} state the problem of reducing the constant from $2$ to $1$ in \cref{old_best} as an open problem.  In the current work, we resolve this open problem:

  \begin{thm}\label{main_result}
    For each fixed graph $H$, the class of $H$-minor-free graphs
    \begin{itemize}[nosep,nolistsep]
      \item admits a $(1+o(1))\log n$-bit adjacency labelling scheme; and

      \item admits $n^{1+o(1)}$-vertex universal graphs.
    \end{itemize}
  \end{thm}


  Many recent results in this area are based on an adjacency labelling scheme due to \citet{dujmovic.esperet.ea:adjacency} for graphs that have so-called ``product structure.''  Indeed, the labelling schemes for planar, bounded genus, apex-minor-free (\cref{apex_minor_free}), and all of the ``beyond planar'' graph classes follow immediately from the fact that all graphs in these graph classes have product structure.

  \section{Building Blocks}

  In this paper, all graphs are finite, simple, and undirected.  For a graph $G$, \defin{$V(G)$} denotes the vertex set of $G$, \defin{$E(G)$} denotes the edge set of $G$, and \defin{$K(G)$} denotes the set of cliques in $G$. For standard graph theory terms, we refer the reader to the textbook by \citet{diestel:graph}.


  Let $T$ be a rooted tree and let $r$ denote the root of $T$. For each $x\in V(T)$, the \defin{$x$-to-root path} \defin{$P_T(x)$} is the path in $T$ from $x$ to $r$.  For each $x\in V(T)$, the \defin{$T$-depth} \defin{$\depth_T(x)$} is the number of edges in $P_T(x)$. For each $i\in\N^+$, the \defin{$i$-th layer} of $T$ is $\mathdefin{L_i(T)}:=\{x\in V(T):\depth_T(x)=i-1\}$. (Note the ${}-1$ in this definition, which ensures that the layers are numbered with positive integers.)  For each $x\in V(T)$ and each $a\in V(P_T(x))$ (including $x$),  the vertex $a$ is a $T$-ancestor of $x$ and $x$ is a \defin{$T$-descendant} of $a$.  For each $x\in V(T)$, \defin{$T_x$} denotes the subtree of $T$ induced by all $T$-descendants of $x$ (including $x$).  For each edge $xy$ of $T$ where $x$ is a $T$-ancestor of $y$, we say that $x$ is the \defin{$T$-parent} of $y$ and $y$ is a \defin{$T$-child} of $x$.  For any set $S\subseteq V(T)$, the \defin{lowest common $T$-ancestor} of $S$ is the node in $\bigcap_{x\in S}P_T(x)$ of maximum $T$-depth.


  A \defin{tree decomposition} of a graph $G$ is a collection $(B_x:x\in V(T))$ of subsets of vertices of $G$ indexed by the nodes of a tree $T$ such that
  \begin{enumerate*}[label=(\alph*)]
    \item for each $v\in V(G)$, $T[\{x\in V(T):v\in B_x\}]$ is a non-empty connected subtree of $T$; and
    \item for each $vw\in E(G)$, $\{v,w\}\subseteq B_x$ for some $x\in V(T)$.
  \end{enumerate*}
  The \defin{adhesion-width} of a tree decomposition $(B_x:x\in V(T))$ is $\max\{|B_x\cap B_y|:xy\in E(T)\}$.  For a tree decomposition $(B_x:x\in V(T))$ of a graph $G$, the \defin{torso} of $x\in V(T)$, denoted \defin{$\torso{G}{B_x}$} is the supergraph of $G[B_x]$ obtained by adding an edge between $v$ and $w$ for each $\{\{v,w\}\in\binom{B_x\cap B_y}{2}$ and each $y\in N_T(x)$.\footnote{The notation $\torso{G}{B_x}$ introduces some minor ambiguity since the definition of $\torso{G}{B_x}$ depends on $(B_y:y\in N_T(x))$, but the notation makes no reference to the tree decomposition $(B_z:z\in V(T))$.  When we use this notation, the tree decomposition will always be obvious from context.}

  A tree decomposition $(B_x:x\in v(T))$ is \defin{normal} if, for any two edges $e:=xy$ and $e':=x'y'$ of $T$, $B_x\cap B_y=B_{x'}\cap B_{y'}$ implies that $e$ and $e'$ are incident to a common node of $T$.  We note that, for any tree decomposition $\mathcal{T}:=(B_x:x\in V(T))$ of a graph $G$ there exists a tree $T'$ with $V(T')=V(T)$ such that $\mathcal{T}':=(B_x:x\in V(T'))$ is a normal tree decomposition of $G$.\pat{Decide if we want to use this definition.   When $P$ is path, a tree-decomposition $(B_x:x\in V(P))$ of a graph $G$ is called a \defin{path-decomposition} of $G$.  In this case, we simplify notation by assuming that $P:=1,2,\ldots,r$ and write ``$B_1,\ldots,B_r$ is a path decomposition of $G$.''

  \subsection{Weight Functions}

  For a set $S$, a \defin{weight function} over $S$ is a mapping $\omega:S\to\R^+$ of the elements of $S$ onto positive real numbers.  When $X$ is a subset of $S$, we use the shorthand $\mathdefin{\omega(X)}:=\sum_{x\in S}\omega(x)$.  When $S:=V(G)$ is the vertex set of a graph $G$ and $H$ is a subgraph of $G$, we use the shorthand $\mathdefin{\omega(H)}:=\sum_{x\in V(H)}\omega(x)$.


  \subsection{Degenerate Labelling Schemes}

  A graph $G$ is \defin{$d$-degenerate} if every subgraph of $G$ contains a vertex of degree at most $d$. A graph class $\mathcal{G}$ is $d$-degenerate if every graph in $\mathcal{G}$ is $d$-degenerate. We make use of the following result, which was first used by \citet{muller:local} to find $\lceil 6\log n\rceil$-bit adjacency labelling schemes for planar graphs:
  % \footnote{The labelling scheme is \cref{degenerate_labelling_scheme} is simple: Each vertex $v$ of $G$ is assigned a unique identifier $\iota(v)\in \{1,\ldots,n\}$. The label for a vertex $v$ with neighbours $v_1,\ldots,v_{d'}$ encodes the sequence $\iota(v),\iota(v_1),\ldots,\iota(v_{d'},) sequence of $d+1$ identifiers: $\iota(v)$ followed by $(\iota(w))_{w\in N_G(v)}$.}

  \begin{thm}\label{degenerate_labelling_scheme}
    For each $d\in\N$, there exists a $\lceil(d+1)\log n\rceil$-bit adjacency labelling scheme for the class of $d$-degenerate graphs.
  \end{thm}




  \subsection{Shannon and Shannon-Fano-Elias Codes}

  A \defin{code} for a set $S$ is a function $\lambda:S\to\{0,1\}^*$ that maps each element in $S$ to a binary string.  A code is \defin{prefix-free} if $\lambda(x)$ is not a prefix of $\lambda(y)$ for any distinct $x,y\in S$.

  We make use of the following result on Shannon Codes:


  \begin{lem}\label{shannon_code}
    Let $S$ be a non-empty set, let $\omega:S\to\R^+$.  Then there exists a prefix-free code $\pi:S\to\{0,1\}^*$ such that $|\pi(x)|\le \log\omega(S)-\log\omega(x)+1$ for each $x\in S$.
  \end{lem}

  A \defin{rooted ordered binary tree} is a rooted tree with at least two leaves in which each non-leaf node has two children, a \defin{left} child, and a \defin{right} child.  A rooted ordered binary tree $T$ induces an ordering on the the leaves of $T$ in which the leaf descendants  of the left child of $x$ precede the leaf descendants of the right child of $x$ for each non-leaf node $x$ of $T$. We make use of the following classical result on Alphabetic Binary Trees:


  \begin{lem}\label{shannon_fano_elias_tree}\label{shannon_fano_elias}
    Let $r$ be an integer, let $\omega:[r]\to\R^+$.  Then there exists a rooted ordered binary tree $T_\omega$ whose leaves, in order, are the integers $1,\ldots,r$ and such that $\depth_{T_\omega}(i)\le \log\omega([r]) - \log\omega(i) + 2$, for each $i\in[r]$.
  \end{lem}

  In coding theory, \cref{shannon_fano_elias} is the basis of the Shannon-Fano-Elias coding scheme, as we now explain.  By assigning each edge of $T_\alpha$ a zero or one depending on whether the edge joins a parent to its left or right child, we obtain an encoding of each root-to-leaf path in $T_\alpha$ as a binary string with the following properties:

  \begin{cor}\label{shannon_fano_elias_code}\label{shannon_fano_elias_cor}
    Let $r$ be an integer, let $\omega:\{1,\ldots,r\}\to\R^+$.  Then there exists a function $\rho:[r]\to \{0,1\}^\star$ such that
    \begin{enumerate}[nosep,nolistsep,label=(\alph*)]
      \item $|\rho(i)|\le \log\omega(\{1,\ldots,r\}) - \log\omega(i)+2$ for each $i\in\{1,\ldots,r\}$ and
      \item $\rho(i)$ is lexicographically less than $\rho(j)$ for each $1\le i < j\le r$.
    \end{enumerate}
  \end{cor}



  \subsection{Separators with Low Pathwidth and Low Path-Adhesion-Width}


  \begin{lem}\label{low_pathwidth_separator}
    Let $T$ be a rooted tree, let $\omega:V(T)\to\R^+$, let $\alpha\in(0,1)$, and let $X_0:=\{x\in V(T):\omega(T_x)>\alpha\cdot\omega(T)\}$.  Then
    \begin{enumerate}[nosep,nolistsep,label=(\alph*)]
      \item\label{connected} $T[X_0]$ is connected and contains the root of $T$;
      \item\label{skinny} $|X_0\cap L_i(T)|\le 1/\alpha$, for each $i\in\N$; and
      \item\label{light} $\omega(C):=\sum_{y\in V(C)}\omega(y)\le \alpha\cdot\omega(T)$ for each component $C$ of $T-X_0$.
    \end{enumerate}
  \end{lem}

  \begin{proof}
    \noindent\ref{connected}:  Since $\alpha <1$, $\omega(T_r)=\omega(T)>\alpha\cdot\omega(T)$, so $X_0$ contains the root $r$ of $T$.  For each $y\in X_0\setminus\{r\}$, $X_0$ contains the $T$-parent $x$ of $y$ since $\omega(T_x)\ge \omega(x)+\omega(T_y)>\omega(T_y)>\alpha\cdot\omega(T)$.  Therefore $T[X]$ contains the root $r$ of $T$ and, for each non-root node $y\in X$, $X$ contains the parent of $y$. Thus $T[X]$ is connected.

    \noindent\ref{skinny}:
    Let $X_i:=X\cap L_i(T)$ for each $i\in\N$.  For each $i\in\N$, the subtrees in $\{T_x:x\in X_i\}$ are pairwise vertex-disjoint, so $\omega(T) \ge \sum_{x\in X_i} \omega(T_x)> |X_i|\cdot\alpha\cdot\omega(T)$.  Rewriting this inequality gives $|X_i|<1/\alpha$ for each $i\in\N$.

    \noindent\ref{light}:
    Each component $C$ of $T-X$ is a subtree of $T$ that is rooted at some node $y$ whose $T$-parent is in $X$.  Since  $y\not\in X$, $\omega(C)=\omega(T_y)\le \alpha\cdot\omega(T)$.
  \end{proof}

    \noindent\ref{x_adhesion}:  For each $i\ge 0$, let $B_i:=\bigcup_{x\in L_{i}(T)\cap X} B_x$ and let $r:=\max\{i\ge 1:B_i\neq\emptyset\}$. That $B_1,\ldots,B_r$ is a path decomposition of $G[\bigcup_{x\in X} B_x]$ follows from the fact that $T$ is a tree decomposition of $G$ and that, for each $i\ge 2$ and each $y\in X\cap L_i(T)$, the $T$-parent $x$ of $y$ is in $X\cap L_{i-1}(T)$.

    Now we show that the adhesion-width of $B_1,\ldots,B_r$ is less than $2k/\alpha$.  Let $A_1:=\emptyset$ and let $A_i:=B_{i}\cap B_{i-1}$ for each $i\in\{2,\ldots,r\}$. Fix $i\in\{1,\ldots,r\}$.  We must show that $|A_i|<2k/\alpha$.  Let $v\in A_i$. Then $v$ is contained in $A_y=B_x\cap B_y$, where $x\in X_0\cap L_{i-1}(T)$, $y\in L_i(T)$ and $xy$ is an edge of $T$. We say that $v$ is of Type~0 if $y\in X_{0}$ and $v$ is of Type~1 if $y\in X\setminus X_0$.  The number of Type~0 vertices in $A_i$ is less than $k/\alpha$ since the number of nodes in $X_{0}\cap L_i(T)$ is less than $1/\alpha$ and $|A_y|\le k$ for each $y\in X_{0}$.

    All that remains is to show that the number of Type~1 vertices in $A_i$ is at most $k/\alpha$. Say  that $(x,K)$ is a \defin{heavy pair} if $x\in X\cap L_{i-1}(T)$, $K$ is a clique in $\torso{G}{B_x}$ and $\omega(x,K)>\alpha n$. We will show that the number of heavy pairs is less than $1/\alpha$. This is sufficient, since each Type~1 vertex in $A_i$ belongs to a clique $K$ in $\bigcup_{x\in X\cap L_{i-1}(T)}\torso{G}{B_x}$ with $\omega(x,K)>\alpha n$, and each maximal clique in $\torso{G}{B_x}$ has size at most $k$.

    Let $\mathcal{P}$ be the set of heavy pairs. For each $(x,K)\in\mathcal{P}$, define $C_{x,K}:=\bigcup_{y\in Y_{\mathcal{T}}(x,K)}\bigcup_{z\in V(T_y)}B_z\setminus V(K)$.  Then $|C_{x,K}|\ge\omega(x,K)>\alpha n$.  Furthermore, for two distinct heavy pairs $(x,K),(x',K')\in \mathcal{K}$, $C_{x,K}$ and $C_{x',K'}$ are disjoint.  Therefore,
    \[
      n\ge\left|\bigcup_{(x,K)\in\mathcal{P}} C_{x,K}\right| \ge \sum_{(x,K)\in\mathcal{P}} \omega(x,K) > |\mathcal{P}|\alpha n \enspace .
    \]
    Dividing both sides by $\alpha n$ shows that $|\mathcal{K}| < 1/\alpha$.

    \noindent\ref{x_alpha}: Assume, for the sake of contradiction, that
    \begin{equation}
       \left|\bigcup_{y\in Y_{\mathcal{T}}(x,K)\setminus X}\medspace \bigcup_{z\in V(T_y)}B_z\setminus V(K)\right| > \alpha n \enspace . \label{contra}
    \end{equation}
    for some $x\in X$ and some clique $K$ in $\torso{G}{B_x}$.  Equivalently, $\sum_{y\in Y_{\mathcal{T}}(x,K)\setminus X}\omega(T_y) > \alpha n$.  Therefore, $\omega(T_x) \ge \omega(x,K) > \alpha n$, so $x\in X_0$. Furthermore,
    \[
      \omega(x,K)
       = \sum_{y\in Y_{\mathcal{T}}(x,K)\setminus X_0}\omega(T_y)
       \ge \sum_{y\in Y_{\mathcal{T}}(x,K)\setminus X}\omega(T_y)
    \]
    Then, by definition, every vertex in $Y_{\mathcal{T}}(x,K)\subseteq X$, so
    \[
      \sum_{y\in Y_{\mathcal{T}}(x,K)\setminus X} \omega(T_y)=\sum_{y\in \emptyset}\omega(T_y)=0 \enspace ,
    \]
    contradicting \eqref{contra}.
  \end{proof}

      \item\label{dejmmw_part_b} For each $i\in\{1,\ldots,r\}$, each $x\in X_i$, each clique $K$ in $\torso{G}{B_x}-A_x$, and each $w\in V^-_{x,K}$, the label for $w$ contains $\lambda_x(K)$

      Since $\omega_{x}(K)=|V^-_{x,K}|$, $\omega_x(v)\ge|V^-_{x,k}|$ for each $v\in V(K)$. Therefore, this part of $w$'s label has length at most
      \begin{align*}
        \log (k\cdot\omega_i(x))-\log\left(\min_{w\in V(K)}\omega(w)\right) + g(n)
        % & \le \log \omega_i(x)-\log\omega(\kappa(xy))+g(n) + O(\log k) \\
        & \le \log \omega_i(x)-\log |V^-_{x,K}| + c\cdot g(n)  \enspace .
      \end{align*}
    \end{enumerate}

    The next part of our labels is only for vertices that are not in $\bigcup_{x\in X}(B_x\setminus A_x)$. For each $x\in X$, each clique $K$ in $\torso{G}{B_x}$, the subgraph $G':=G[V^-_{x,K}]$ has at most $\alpha n$ vertices.  The subgraph $G'$ has a tree decomposition $(B'_z:z\in V(T'))$ obtained as follows: Let $T'$ be the tree obtained from the forest $\bigcup_{y\in Y_{\mathcal{T}}}\setminus X$ T_y$ by adding a new vertex $x'$ and adding the edge $x'y$ for each node $y\in Y_{\mathcal{T}}}\setminus X$.  Set $B'_{x'}:=\emptyset$ and set $B'_z:=B_z\setminus B_x$ for each $z\in V(T')\setminus\{x'\}$.  We recursively label the vertices in $G'$ using the tree decomposition $\mathcal{T}'$ to obtain a labelling $\lambda_{x,K}:V^-_{x,K}\to\{0,1\}^*$.

    \begin{enumerate}[nosep,nolistsep,label=(P\arabic*)]\setcounter{enumi}{6}
      \item\label{recursive_part} For each $i\in\{1,\ldots,r\}$, each $x\in X_i$,  each clique $K$ in $\torso{G}{B_x}-A_x$ and each vertex $w\in V^-_{x,k}$, the label for $w$ includes $\lambda_{x,K}(w)$.  Let $z$ be the node of $T$ such that $w\in B_z$.  (So $z\neq x$ is a $T$-descendant of $x$.)  By the inductive hypothesis,
      \begin{align*}
        |\lambda_{x,K}(w)|
        & \le \log |V^-_{x,K}|+\frac{g(n)\log(\alpha n)}{\log(1/\alpha)}+ ck|B'_z|(\log k/\alpha)+k\log\log n) \\
        & = \log\omega_x(K) + \frac{g(n)\log(n)}{\log(1/\alpha)} -g(n) + ck|A_z\setminus A_x|(\log k/\alpha)+k\log\log n) \\
        & = \log\omega(x,K) + \sqrt{k\cdot g(n)\log n} -g(n) + ck|A_z\setminus A_x|(\log k/\alpha)+k\log\log n) \enspace .
      \end{align*}
    \end{enumerate}

    The final part of our labels is used so that, for each $x\in X$, each $T$-descendant $z$ of $x$, and each $w\in B_z$, the label of $w$ contains enough information to identify the label of $v$, for each $v\in B_x\cap A_z$.

    \begin{enumerate}[nosep,nolistsep,label=(P\arabic*)]\setcounter{enumi}{7}
      \item\label{apex_edges} For each $x\in X$ and, each $z\in V(T^-_x)$ and each $w\in B_z\setminus A_z$, the label for $w$ will contain a part for each vertex $v\in A_z\cap B_x$.  This part of $w$'s label contains one bit indicating whether $vw\in E(G)$ and two bits indicating which of the following cases applies:

      \begin{enumerate}[nosep,nolistsep,label=(P8\alph*)]
        \item\label{q_part} If $v\in A_x$, then $a(v)<i$ and $b(v)\ge i$. Therefore $q(v)$ is a $T_\omega$-ancestor of $i$.  In this case, the label for $w$ contains $\varphi(v)$ and $\depth_{T_\alpha}(q(v))$ (defined in parts \ref{lca_part} and \ref{colour_part} of $v$'s label). This part of $w$'s label has length at most $c(\log(k/\alpha) + \log\log n)$.

        \item\label{nothing_part} If $v\in B_x\setminus A_x$ and $z= x$ then $v$ and $w$ are both vertices in $G[B_x]-A_x$. In this case, \ref{dejmmw_part} already contains enough information to test the presence of the edge $vw$, so no additional information is included in $w$'s label.

        \item\label{clique_part} If $v\in B_x\setminus A_x$ and $z\neq x$, then $z$ is a strict $T$-descendant of $x$.  In this case, $w\in V^-{x,K}$ for clique $K$ in $\torso{G}{B_x}-A_x$ and part \ref{dejmmw_part} of the label for $w$ contains the label $\lambda_x(K)$.  By the definition of mixed labellings, there exists an ordering $v_1,\ldots,v_{k'}$ of $V(K)$ such that $\mu(\lambda_x(v),\lambda_x(K),i)=1$ if and only if $v=v_i$. Let $\iota(v)\in\{1,\ldots,k'\}$ be the unique index such that $v=v_{\iota(v)}$.  In this case, the label for $w$ contains $c\log k$ bits to store $\iota(v)$.

        \item If $v\not\in B_x$, then $v$ and $w$ are both vertices in $V^-_{x,K}$ for some clique $K$ in $\torso{G}{B_x}-A_x$.  In this case, the part~\ref{recursive_part} of the labels for $v$ and $w$ contain $\lambda_{x,K}(v)$ and $\lambda_{x,K}(w)$, which can be used to test for the existence of the edge $vw$ in $G[V^-_{x,K}]$. In this case, no additional information is included in $w$'s label.
      \end{enumerate}
    \end{enumerate}

    Given the labels of two vertices $v$ and $w$ in $G$, the adjacency testing function begins by comparing $\rho(v)$ and $\rho(w)$ from part~\ref{rho_part} of their respective labels:
    \begin{enumerate}
      \item If $\rho(v)\neq \rho(w)$ then assume, without loss of generality, that $\rho(v)$ is lexicographically smaller than $\rho(w)$.  This means that $v\in B_i\setminus A_i$ and $w\in B_j\setminus A_j$ for some $1\le i < j\le r$.  This implies that $v\in V^-_{x'}\setminus A_{x'}$ for some $x'\in X_i$. Let $z$ be the unique node of $T$ such that $w\in B_z\setminus A_z$.   In this case, $v$ and $w$ can only be adjacent if $v\in A_x\cap A_z$. First we check, using Part~\ref{flag_part} if $a(v)=b(v)$. If so, then $v\not\in A_x$, so we can immediately deduce that $vw\not\in E(G)$.

      Now assume that $a(v)<b(v)$.  The pair $(q(v),\varphi(v))$ uniquely identifies $v$ in the set $\{v\in V(G):a(v)\neq b(v)\}\supseteq A_x$.  The path $P_{T_\omega}(q(v))$ uniquely identifies $q(v)$ in the set $V(T_\omega)$.  Part~\ref{lca_part} of $v$'s label contains $d:=\depth_{T_\omega}(q(v))$.  The first $d$ bits of $\rho(v)$ describes the path $P_{T_\omega}(q(v))$, and \ref{colour_part} of $v$'s label contains $\varphi(v)$.

      For each $v'\in A_x\cap A_z$, Part~\ref{q_part} of $w$'s label contains $\depth_{T_\omega}(q(v'))$ and $\varphi(v')$.  If $\depth_{T_\omega}(q(v'))\neq d=\depth_{T_\omega}(q(v))$ then we can immediately conclude that $q(v)\neq q(v')$, so $v\neq v'$.  Otherwise, the first $d$ bits of $\rho(w)$ describe $P_{T_\omega}(q(v'))$.  Therefore, for each $v'\in A_x\cap A_z$, we can test if $v'=v$ by checking if the first $d$ bits of $\rho(w)$ and the first $d$-bits of $\rho(v)$ are equal and if $\varphi(v')=\varphi(v)$.  If $v'=v$ for some $v'\in A_x\cap A_z$ then a bit in part~\ref{apex_edges} of $w$'s label indicates whether or not the edge $v'w=vw\in E(G)$.

      \item If $\rho(v) = \rho(w)$, then $v,w\in B_i\setminus A_i$ for some $i\in\{1,\ldots,r\}$.  In this case, we compare $\pi_i(v)$ and $\pi_i(w)$.  If $\pi_i(v)\neq\pi_i(w)$, then $v\in V^-_x\setminus A_x$ and $w\in V^-_{x'}\setminus A_{x'}$ for distinct $x,x'\in X_i=L_i(T)\cap X$.  In this case we can immediately conclude that $vw\not\in E(G)$.

      Now suppose $\pi_i(v)=\pi_i(w)$, which implies that $v,w\in V^-_x$ for some $x\in X_i$. In this case, we inspect the two bits of part \ref{apex_edges} of $v$'s and $w$'s labels.  Up to renaming $v$ and $w$, there are three possibilities:
      \begin{enumerate}
        \item $v\in B_x\setminus A_x$ and $w\in B_x\setminus A_x$.  In this case $v$ and $w$ are both vertices in the graph $G[B_x]$ and we can test for the presence of the edge $vw$ using $\lambda_x(v)$ and $\lambda_x(w)$ from part~\ref{dejmmw_part}.
        \item $v\in B_x\setminus A_x$ and $w\in V^-_x\setminus B_x$.  In this case $w\in V^-_{x,K}$ for some clique $K$ in $\torso{G}{B_x}-A_x$. Part~\ref{dejmmw_part_b} of $w$'s label contains $\lambda_x(K)$.

        Part~\ref{clique_part} of $w$'s label contains, for each $v'\in A_z\cap B_x\setminus A_x=A_z\cap V(K)$ the index $i:=\iota(v')$ of $v'$ in the clique $K$. For each $v'\in A_x\cap A_z$, the mixed labelling scheme for $\torso{G}{B_x}$ includes a testing function $\mu$ such that $\mu(\lambda(v),\lambda(K),i)=1$ if and only if $v'=v$.  If $v'=v$ for some $v'\in A_x\cap A_z$ then an additional bit in part~\ref{apex_edges} of $w$'s label indicates whether the edge $v'w=vw\in E(G)$.  If $v'\neq v$ for any $v'\in B_z\cap B_x$, then $v\not\in V(K)=A_y$, so $vw\not\in E(G)$.

        \item $v\in V^-_x\setminus B_x$ and $w\in V^-_x\setminus B_x$.  In this case, we compare $\lambda_x(v)$ and $\lambda_x(w)$.  If $\lambda_x(v)\neq\lambda_x(w)$ then $v\in V^-_{x,K}$ and $w\in V^-_{x,K'}$ for distinct cliques $K$ and $K'$ in $\torso{G}{B_x}-A_x$, in which case we can immediately conclude that $vw\not\in E(G)$.
        If $\lambda_x(v)=\lambda_x(w)$ then $v$ and $w$ are both in $V^-_{x,K}$ for some clique $K$ in $\torso{G}{B_x}-A_x$.  In this case, we can test for the presence of the edge $vw$ in $G_{x,K}$ using $\lambda_{x,K}(v)$ and $\lambda_{x,K}(w)$ from part~\ref{recursive_part} of their labels. \qedhere
      \end{enumerate}
    \end{enumerate}
  \end{proof}
